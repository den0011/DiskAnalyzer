# DiskAnalyzer — Анализатор дискового пространства

Десктопное приложение для анализа дискового пространства. Позволяет сканировать директории и наглядно визуализировать, какие файлы и папки занимают больше всего места на диске.

![](https://github.com/den0011/DiskAnalyzer/blob/1.0.0-version/1.jpg)

## Стек технологий

- **Язык:** C++ (стандарт C++17)
- **GUI-фреймворк:** Qt 5+ (Qt Widgets, Qt Charts, Qt Concurrent)
- **Сборка:** QMake
- **Платформа:** Windows

## Возможности

- Рекурсивное сканирование директорий с многопоточной обработкой
- Визуализация в виде **Sunburst-диаграммы** с интерактивной навигацией
- **Круговая диаграмма** распределения по папкам
- **Таблица крупнейших файлов** с сортировкой и контекстным меню
- Отображение прогресса сканирования в реальном времени
- Отмена сканирования в любой момент

## Структура проекта

```
├── main.cpp              # Точка входа
├── mainwindow.h/cpp/ui   # Главное окно приложения
├── scanner.h/cpp         # Движок сканирования (многопоточный)
├── fileitem.h/cpp        # Модель данных файлов и папок
├── sunburstwidget.h/cpp  # Виджет Sunburst-диаграммы
├── DiskAnalyzer.pro      # Конфигурация проекта QMake
├── file.rc               # Ресурсный файл Windows (иконка)
└── 1.ico                 # Иконка приложения
```

## Архитектура

Приложение построено на паттерне сигналов и слотов Qt:

1. **MainWindow** — оркестратор UI, управляет взаимодействием компонентов
2. **Scanner** — многопоточный движок сканирования файловой системы через QThreadPool
3. **FileItem** — древовидная модель данных с кэшированием размеров (`std::shared_ptr`)
4. **SunburstWidget** — кастомный виджет для отрисовки радиальной диаграммы

Сканирование выполняется в пуле потоков, прогресс передаётся в UI через атомарные счётчики и сигналы Qt.

## Сборка и запуск

```bash
qmake DiskAnalyzer.pro
make
./DiskAnalyzer
```

**Требования:** Qt 5+ с модулями `core`, `gui`, `widgets`, `charts`, `concurrent`.
